世の中のウラ側を、短く深く。

「ネムとモグの解説室」は、経済・心理・歴史・科学・AIなどの「直感と結果が食い違う話」を、大人向けにコンパクトに解説するYouTubeチャンネルです。 落ち着いた解説役の白猫・ネムと、疑問を代弁するハムスター・モグの掛け合いでお届けします。

制作用ツールについて

このサイトは、チャンネルの運営者が自分のチャンネルを管理するために使う制作用ツール「ネムとモグの解説室 制作ツール」の案内も兼ねています。 このツールは、運営者本人のYouTubeチャンネルに対してだけ、Google の OAuth で許可を得て YouTube Data API と YouTube Analytics API を使います。

  • 運営者が作った動画・サムネイル・字幕を、自分のチャンネルにアップロードする
  • 自分のチャンネルの動画のタイトル・説明・公開日時・再生リストを整える
  • 自分のチャンネルの再生数や視聴維持率を読み、次の動画づくりに生かす

一般の方に向けて提供しているサービスではなく、ほかの方のアカウントやデータを扱うことはありません。 詳しくはプライバシーポリシーをご覧ください。

About the production tool. This site also documents “Nemu & Mogu Production Tool”, a private tool the channel owner uses to manage their own YouTube channel. With the owner’s consent via Google OAuth, it uses the YouTube Data API and the YouTube Analytics API only on the owner’s channel: uploading the owner’s videos, thumbnails and captions; editing titles, descriptions, schedules and playlists; and reading the channel’s own analytics. It is not offered to the public and does not access anyone else’s account or data. See the Privacy Policy.
